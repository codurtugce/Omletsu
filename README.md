# 🐱 Omletsu

Omletsu is a cute interactive desktop cat for Windows.

It quietly waits in the background and appears when your computer has been idle for a while.

## ✨ Features

- 🐾 Walks around your desktop
- 😸 Sits and rests
- 🐈 Wags its tail
- 👅 Grooms itself
- ⏱ Adjustable idle time
  - 30 seconds
  - 1 minute
  - 2 minutes
  - 3 minutes
  - 4 minutes
  - 5 minutes
- 🖥 System tray controls
- 🚀 Optional startup with Windows
- 🔒 Only one Omletsu can run at a time

## 📥 Download

Go to the **Releases** section and download:

`OmletsuSetup.exe`

Then run the installer and follow the setup steps.

## 🖱 Controls

Right-click the Omletsu icon in the Windows system tray:

- Show Omletsu
- Hide Omletsu
- Automatic Mode
- Idle Time
- Start with Windows
- Exit

## 💻 Requirements

- Windows 10 / Windows 11
- 64-bit Windows
